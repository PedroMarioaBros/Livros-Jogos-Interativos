# Fontes e direitos

Este repositório foi estruturado para armazenar o software e os dados técnicos da adaptação, não para redistribuir os livros originais.

## Pode entrar no repositório

- código do motor;
- estruturas JSON;
- regras implementadas;
- referências numéricas;
- relações entre estados;
- resumos técnicos escritos para o projeto;
- artes, sons e textos originais criados para a interface;
- testes e documentação técnica.

## Não deve entrar

- scans integrais;
- PDFs integrais;
- OCR integral;
- páginas reproduzidas em massa;
- ilustrações originais copiadas dos livros;
- qualquer material-fonte cuja redistribuição não esteja autorizada.

## Fonte de trabalho

Fúria de Príncipes corresponde à edição brasileira de **Clash of the Princes**, composta por dois volumes: O Caminho do Guerreiro e O Caminho do Feiticeiro.

Durante a implementação, informações extraídas de fontes de consulta devem ser convertidas em estrutura funcional e resumos próprios, com validação separada para evitar que erros de OCR entrem no banco narrativo.
